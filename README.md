# HerHealth — Women's Healthcare & Health Awareness

HerHealth is a women's healthcare platform for menstrual cycle tracking, PCOS/PCOD education, nutrition, and health awareness.

## Features
- Menstrual cycle tracker and calendar
- Personal health records
- PCOS and PCOD educational resources
- Indian nutrition guidance
- Women's health education library
- Educational health assistant
- Daily self-care checklist
- Privacy and consent controls

## Technology Stack
- React, TypeScript, Vite, Tailwind CSS
- Supabase, PostgreSQL, Supabase Auth
- Row Level Security (RLS)
- Vitest testing

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Medical Disclaimer
HerHealth provides health education and wellness tracking, not medical diagnosis or treatment. Consult a qualified healthcare professional for medical advice.
